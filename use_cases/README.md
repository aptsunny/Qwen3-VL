## 核心痛点总结

根据我们的实践经验，Qwen3-VL 在高通芯片部署中遇到的主要痛点包括：

### 1. ViT 单独标定损失大
- **问题**：先前按 ViT 单独用 COCO 标定、再整体导出评估的方式在多模态任务上量化损失偏大
- **影响**：多模态任务精度下降 3-5%
- **需求**：Vision+LLM 整体联合 calibration 方案

### 2. 变长输入处理困难
- **问题**：变长文本（4K/8K）与变化尺寸图像的量化参数难以统一
- **影响**：不同输入长度下精度波动大
- **需求**：动态 shape 支持和分段量化策略

### 3. 标定数据覆盖不足
- **问题**：缺乏多模态图文配对数据的标定工具
- **影响**：校准数据分布无法覆盖常见场景
- **需求**：多模态数据集标定工具或 API

### 4. 量化算法适配不明确
- **问题**：FPTQuant / OmniQuant / SpinQuant 等先进量化算法的具体配置不明确
- **影响**：无法充分利用高通工具链的优化能力
- **需求**：针对 Qwen3-VL 的量化优化 Recipe

### 5. PTQ 精度恢复困难
- **问题**：部分场景 PTQ 精度损失过大（>3%）
- **影响**：无法满足生产环境精度要求
- **需求**：QAT 版本示例和指导

## 对高通的需求清单

### 工具链需求
1. **Interleaved-MRoPE 算子支持**：Qwen3-VL 特有的多模态位置编码
2. **DeepStack 特征融合支持**：多层视觉特征融合算子
3. **动态 shape 编译**：支持变长 batch/seq_len
4. **Per-Head KV 量化**：逐头 KV Cache 量化策略
5. **LoRA 动态加载**：运行时适配器权重融合

### 标定工具需求
1. **多模态联合标定 API**：Vision + LLM 同时标定
2. **视频标定支持**：视频帧采样和时序特征标定
3. **长序列标定工具**：支持 8K-32K 序列长度
4. **自定义数据集接口**：用户可上传图文配对数据

### 精度对比需求
1. **LLM W4A16 ± LPBQ 对比**
2. **KV Cache KV8 vs KV16 对比**
3. **Vision W8A8 vs W8A16 对比**
4. **联合标定 vs 独立标定对比**
